============================================================================
  Apple Music MCP — Linux try-out  (the Windows/Linux path)
============================================================================
A real Debian box with Google Chrome. Off-mac there is no Music.app and no
Safari: data goes through the Apple Music web API, playback through the Chrome
web player. This is exactly what a Windows/Linux user gets.

------------------------------------------------------------ 1. SIGN IN ----
    applemusic-mcp login

A Chrome window opens on music.apple.com. Sign in with your Apple ID and
complete two-factor as prompted.

Heads-up: USB security keys can't pass through Docker on a Mac, so if your
Apple ID *requires* a hardware key, interactive sign-in here won't work.
Sign in where the key works and inject the token instead — see
docker/linux-tryout/README.md ("Token injection").

------------------------------------------------------------ 2. CHECK -------
    applemusic-mcp status        # should show: User token present, API ok

------------------------------------------------------------ 3. TRY IT ------
    python ~/smoke.py            # search + play + queue, end to end

Notes
  - No audio is routed out of the container (by design). We confirm playback
    STARTS and the queue works — not that you can hear it.
  - Your sign-in persists in a docker volume across restarts.
  - Full-length playback needs Google Chrome (installed here) for Widevine;
    that's why this box uses Chrome, not bundled Chromium.
